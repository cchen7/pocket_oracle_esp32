# UI Design Language — Pocket Oracle

> 给所有 app 共用的视觉/动效规范。每个 app 必须遵守，不许自行加色加字号。

## 视觉基调

- **极简但不寡淡**：色彩节制，留白慷慨，关键信息有重量
- **东方禅意**：圆角、柔和过渡，避免硬朗的科技感
- **手感优先**：每次按键都有视觉/音频反馈

不要：霓虹蓝、矩阵字体、过度装饰、硬阴影、stock 图标。

## 色板（最多 7 个语义色）

### 浅色模式（默认白天）

| 角色 | 颜色 | 用途 |
|---|---|---|
| `bg.primary` | `#FAF7F2` 米白 | 全局背景 |
| `bg.elevated` | `#FFFFFF` 纯白 | 卡片 / 弹层 |
| `ink.primary` | `#1B1A18` 深墨 | 主文字 |
| `ink.secondary` | `#8E8B85` 灰 | 副文字、按钮提示 |
| `accent.main` | `#C9A968` 暖金 | 强调、主按钮、运势"宜" |
| `accent.warn` | `#B0524A` 朱砂 | 运势"忌"、错误 |
| `accent.calm` | `#7B8E8B` 青灰 | 提示、链接、信息态 |

### 暗色模式（默认夜晚）

| 角色 | 颜色 |
|---|---|
| `bg.primary` | `#1B1A18` 深墨 |
| `bg.elevated` | `#26241F` 暖深灰 |
| `ink.primary` | `#F2EEE6` 米白 |
| `ink.secondary` | `#A09C95` 中灰 |
| `accent.main` | `#D9B978` 提亮暖金 |
| `accent.warn` | `#C26B62` 提亮朱砂 |
| `accent.calm` | `#8FA09D` 提亮青灰 |

切换策略：
- **自动**（默认）：白天 6:00-19:00 浅色，其余暗色
- **始终浅**
- **始终深**

## 字体

字体族：**Alibaba Puhui Sans (开源)**，CJK 全覆盖。

| 用途 | 字号 | 字重 | 字符集 |
|---|---|---|---|
| 大标题 (运势 宜/忌、答案首字、时钟数字) | 48 pt | Bold | 数字 + 标点 + ~300 高频汉字 |
| 中标题 (应用名、菜单项) | 32 pt | Medium | 数字 + 标点 + ~500 字 |
| 正文 (答案全文、MBTI 提示) | 16 pt | Regular | 完整 CJK (~6700 字) |
| 副文 (状态栏、按钮提示) | 12 pt | Regular | 完整 CJK |
| 数字大字 (时钟 HH:MM) | 64 pt | Mono Bold | 仅 0-9 + 冒号 |

字体表预算 ~600 KB。生成脚本 `tools/gen_fonts.sh` 用 `lv_font_conv` + glyph list 控制各字号字符集。

## 布局网格

- **8px 基线**：所有间距是 8 的倍数 (8/16/24/32)
- **安全边距**：屏幕四边各 8px 净空
- **横屏 240×135**：M5.Display.setRotation(1 或 3)，UI 设计按这个方向
- **状态栏**：顶部 16px
- **按钮提示行**：底部 16px
- **内容区**：中间 224 × ~100 px

```
┌─────────────────────────────────┐  8 ↓
│  ▍ 09:42  ⚡85%  📶  ☊         │  status_bar 16px
├─────────────────────────────────┤
│                                 │
│        [content area]           │  ~100px
│                                 │
├─────────────────────────────────┤
│  短按确认 · 长按返回             │  button_hints 16px
└─────────────────────────────────┘  8 ↑
```

## 动效

| 场景 | 缓动 | 时长 |
|---|---|---|
| 切屏 (app push/pop) | `ease-out-cubic` | 300 ms |
| 按键反馈 (scale 1.0→0.95→1.0) | `ease-out-quad` | 100 ms |
| 答案/运势文字浮现 | 逐字 fade-in | 80 ms/字 |
| 木鱼敲击 (scale -8% + 复原) | `ease-out-back` | 300 ms |
| 状态变化（如 BLE 连上） | fade | 200 ms |
| splash 开机动画 | 渐显 + 字符浮现 | 1200 ms 总长 |

**减少动效模式**：设置里可关，长按 KEY1 + KEY2 同时可临时禁用（无障碍）。

## 触发反馈

每次有效按键：
1. 视觉：被点元素 100ms 缩放 0.95→1.0
2. 音频：10ms 1kHz beep（音量随设置，可关）

无效操作：
- 视觉：屏幕轻微抖动 (3px 水平，2 来回，100ms)
- 音频：50ms 200Hz 低沉 buzz

## 图标

### 主菜单 app 图标
- 每个 app 一个 32×32 自绘 PNG（不用 FontAwesome 套字体）
- 风格：单色描边 + 圆角，可用 accent.main 着色
- 文件：`firmware/main/data/icons/<app>.png`，CMake 时打包进 framebuffer 静态资源

### 状态栏图标
- FontAwesome 12pt：电池、WiFi、BLE、闹钟
- 复用 `firmware/components/fonts/font_awesome_*`

## 黄金示例屏

### 1. 主菜单
- 12 个 app 排成 3 列 4 行卡片网格
- 每张卡片 64×56 px：上方 32×32 图标 + 下方 12pt 名字
- 当前选中卡片：accent.main 描金边 2px + 阴影抬高
- 长按 KEY2 进入"应用排序"模式

### 2. 答案之书
- 顶部 16pt "今日所问"（副文字）
- 中间 32pt 居中显示答案，逐字浮现
- 底部按钮提示："摇一摇换一条 · 长按返回"

### 3. 每日运势
- 屏幕一分为二：左 48pt "宜：XX"（accent.main 暖金），右 48pt "忌：XX"（accent.warn 朱砂）
- 中间 1px 分隔线
- 底部一行 12pt "幸运色"标签 + 一个 24×8 色块

### 4. 大字时钟
- 屏幕中央 64pt Mono 数字 HH:MM
- 数字下方 16pt "周X · MM 月 DD 日"
- 顶部正常状态栏

### 5. 电子木鱼
- 中央 48×48 木鱼图形
- 上方 32pt 显示功德数
- 下方 12pt "今日 +N"
- 敲击瞬间木鱼 scale -8% + 屏幕轻闪 + "啪嗒"音

## 实现约束

- 所有屏幕代码必须用 `ui/theme.h` 的常量取色取字号，不准 hardcode 颜色值
- 所有间距用 `THEME_SPACE_S/M/L/XL`（8/16/24/32）常量
- 动画一律用 `ui/transitions.h` 提供的 helper，不准每个 app 自己写 `lv_anim_set_*`
- 字体表大小膨胀时（每加一个字号 +~100KB），先评估能否复用现有字号子集
