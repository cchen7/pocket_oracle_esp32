四 · 配 WiFi（可选）

  1. 主菜单 → 设置 → 无线网络
  2. 设备显示 SSID：PocketOracle-XXXX（开放热点）
  3. 手机 WiFi 连此热点，自动弹出网页
  4. 填家庭 WiFi 名 + 密码 → 保存
  5. ~ 4 秒后连上，状态栏出现真实时间
不配 WiFi 也能用，只是时钟显示开机时长不是 wall time。

六 · 蓝牙翻页

  1. 进 蓝牙翻页 app，自动广播 "Pocket Oracle"
  2. 手机 / Mac 蓝牙列表配对（无需密码）
  3. BtnA = 下页 →   BtnB = 上页 ←   摇 = 上页
  4. 长按返回 → 蓝牙断开释放 ~ 50KB 内存
iPhone 重新配对前请到"设置→蓝牙→忽略此设备"清除旧记录。

七 · 小提示

  • 木鱼或开机时听到轻微底噪是硬件特性（AW8737 功放硬接 VBAT），不是故障
  • iPhone 翻页只认方向键，不认 PgUp/PgDn — 本固件已用方向键
  • 500 mAh 电池正常使用约 1–3 天
